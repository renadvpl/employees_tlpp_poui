# Cadastro de Funcionários com interface web PO-UI

Este projeto consiste na elaboração de uma interface web para a inclusão, alteração e visualização de funcionários na base de dados do sistema TOTVS Protheus.
Ele foi iniciado para fixação de conhecimento de TypeScript (JavaScript ECMA6), na qual foi adquirido nas vídeos-aulas do Alisson Lemes do Spirit Fire.
- Angular CLI version 21.2.23.
- TOTVS Protheus versão 12 release 25.10
